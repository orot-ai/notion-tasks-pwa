# Tasks — 노션 기반 모바일 할일 관리 웹앱

> 노션 데이터베이스를 모바일 웹에서 빠르게 다루는 1인용 PWA.

---

## 1. 한 줄 요약

사용자가 자신의 노션 태스크 DB를 모바일 브라우저에서 직접 조회·편집·정리할 수 있는 웹앱.

## 2. 배경 & 목표

### 배경
- 일정과 할일을 노션 DB에 통합 관리하는 사용자가 늘고 있다.
- 노션 모바일 앱은 표 위주라 인지 부담이 크고, 시간축 기반 시각화가 약하다.
- 노션 캘린더 앱은 일정만 잘 보이고, 할일 체크/스와이프 같은 빠른 인터랙션이 부족하다.

### 목표
1. **빠른 인지** — 1초 안에 “지금 무엇을 해야 하는가”를 파악한다.
2. **빠른 수정** — 한 손으로 완료/이동/생성을 할 수 있다.
3. **단일 진실 원천** — 노션 DB가 항상 정답. 앱은 그 DB를 비추는 거울이다.
4. **인지 부하 최소화** — 단순·평면·즉각 피드백·작은 단위 인터랙션.

### 비목표
- 다중 사용자 협업.
- 노션의 다른 DB(이메일·연락처 등) 표시.
- 복잡한 보고서·대시보드.
- 네이티브 앱.

## 3. 사용자

| 페르소나 | 1인 사용자 |
|----------|------------|
| 환경 | 모바일 브라우저 주력, 데스크톱 보조 |
| 특성 | 시각·상황 기반 회상 선호, 빠른 마이크로-인터랙션 선호 |
| 핵심 시나리오 | 잠금 해제 → 홈화면 아이콘 탭 → 다음 할 일 확인 → 한 번 탭으로 처리 → 노션에 즉시 반영 |

## 4. 데이터 모델

### 4.1 핵심 엔티티: Task

```ts
interface Task {
  id: string;              // 노션 page id
  notionId: string;        // 동기 키 (id와 동일)
  title: string;
  start: string | null;    // ISO datetime
  end: string | null;      // ISO datetime
  status: TaskStatus;      // 예정/진행중/보류/완료/취소
  type: TaskType;          // 일정/할일
  projects: string[];      // multi-select 라벨
  description: string;
  createdAt: string;
}
```

### 4.2 노션 DB 요구 스키마

앱이 동작하려면 사용자의 노션 DB에 다음 속성이 있어야 한다.

| 앱 필드 | 노션 속성명 (기본값) | 노션 타입 | R/W |
|---------|--------------------|-----------|-----|
| title | `태스크` | title | R/W |
| start / end | `태스크 기간` | date range | R/W |
| status | `상태` | status (예정/진행중/보류/완료/취소) | R/W |
| type | `유형` | select (일정/할일) | R/W |
| projects | `프로젝트명` | multi_select | R/W (새 옵션 자동 생성) |
| description | `설명` | text | R/W |
| createdAt | `생성 일시` | created_time | R |

> 속성명·옵션값은 코드의 매퍼(`lib/notion-mappers.ts`)에서 변경 가능. 다국어/커스텀 스키마를 쓰려면 매퍼 키만 수정.

### 4.3 앱이 건드리지 않는 노션 속성

- 사용자가 노션에서 수동으로 추가한 속성(formula, relation, 추가 자동화 키 등)은 앱이 무시한다.
- 앱은 PATCH 화이트리스트(7개 필드)만 건드리며, 그 외는 read-only.

> **단일 진실 원천 원칙**: 노션이 정답이고, 앱은 화이트리스트 필드만 수정한다.

## 5. 사용자 흐름

### 5.1 기본 흐름

```
1. 홈화면 아이콘 탭
2. 6자리 패스코드 입력 (30일 유지)
3. 리스트 / 타임라인 / 월간 뷰 사이 하단 탭으로 전환
4. 카드 탭 → 상세 → 편집
5. 변경은 즉시 화면 반영 + 백그라운드로 노션 PATCH
```

### 5.2 빠른 처리 흐름

```
리스트 카드 우→좌 스와이프  =  취소
리스트 카드 좌→우 스와이프  =  내일로 이동
타임라인 블록 0.4초 꾹 누름  =  편집 모드 진입 → 그대로 드래그
```

## 6. 화면 명세

### 6.1 공통 레이아웃

- 폭: 모바일 우선. 리스트 `max-w-md`, 타임라인 `max-w-3xl`, 월간 `max-w-2xl`.
- 상단: sticky 헤더 (제목, 액션 아이콘).
- 하단: 고정 탭바 (3뷰) + safe-area-inset.
- 라이트/다크 자동 (`prefers-color-scheme`).
- 폰트: sans-serif + 시스템 한글 fallback.

### 6.2 리스트 뷰 (`/`)

```
┌──────────────────────────────────────┐
│ 할일                     [🔍] [↻]    │  ← 검색 / 새로고침
│ ──────────────────────────────       │
│ ( 미완료 │ 완료 │ 취소 )              │  ← 상태 (1차)
│ [이번주][지난주][전체]                │  ← 시간 범위 (완료/취소만)
│ [ 전체 ][ 일정 ][ 할일 ]              │  ← 유형
│ [모든 프로젝트 ▾]                     │  ← 프로젝트 (드롭다운 + 검색)
├──────────────────────────────────────┤
│ ● 지각 (2)                     ㅡ ▾  │
│ ● 오늘 (5)                     ㅡ ▾  │
│ ● 이번주 (8)                   ㅡ ▾  │
│ ● 예정 (12)                    ㅡ ▾  │
└──────────────────────────────────────┘
                                 [ + ]
```

#### 필터 계층

| 1차: 상태 | 2차: 시간 (완료/취소만) | 3차: 유형 | 4차: 프로젝트 |
|-----------|--------------------------|-----------|----------------|
| 미완료    | (그룹으로 시간 표현)    | 전체/일정/할일 | 단일 선택 |
| 완료      | 이번주(기본)/지난주/전체 | 전체/일정/할일 | 단일 선택 |
| 취소      | 이번주(기본)/지난주/전체 | 전체/일정/할일 | 단일 선택 |

- **시간 범위 기준**: 시작일이 있으면 그것, 없으면 생성일. 주 시작은 월요일.
- **프로젝트 드롭다운**: 단일 선택 + 검색. 현재 데이터에 실제 있는 프로젝트만 자동 추출 + 가나다순. 옵션 클릭 → 자동 닫힘. 외부 탭 → 자동 닫힘. 선택된 칩 우측 X로 즉시 해제.

#### 핵심 동작

- **그룹 헤더**: 컬러 점(지각=장미, 오늘=앰버, 이번주=블루, 예정=회색, 완료=에메랄드)으로 구분.
- **카드 본체 탭**: 상세 모달 슬라이드 업.
- **체크박스 탭**: 즉시 완료 토글 + 노션 PATCH.
- **카드 우→좌 스와이프**: 취소 (장미 인디케이터).
- **카드 좌→우 스와이프**: 다음날로 이동 (앰버 인디케이터).
- **검색 아이콘**: 인라인 검색바 (제목·설명·프로젝트).
- **FAB(+)**: 새 태스크 모달.
- **새로고침 아이콘**: 노션 재호출 + 회전 애니.

### 6.3 타임라인 뷰 (`/timeline`)

```
┌───────────────────────────────────────────┐
│ ◂ M월 D일 (요일) ▸           [ 오늘 ]    │
│      ( 1일 )( 2일 )( 3일 )                │
├───────────────────────────────────────────┤
│ 6 │   │   │                               │
│ 9 │ ▌이벤트 9-10                          │
│12 │ ▌이벤트 12-14                         │
│14 │ ▌이벤트 14-15  ━━━━━ ← 현재 시각      │
│15 │ ▌이벤트 15-17                         │
└───────────────────────────────────────────┘
                              [ + ]
```

#### 핵심 동작

- **상단 좌우 화살표 / 좌우 스와이프**: 1일 단위 날짜 이동 (3일뷰에서도 1일씩).
- **새 anchor로 전환 시**: spring 슬라이드 모션.
- **1·2·3일 토글**: 화면 가로를 균등 분할.
- **현재 시각 빨간 라인**: 오늘을 포함하는 컬럼에만.
- **빈 시간대 탭**: 그 시간으로 새 태스크 모달 자동 채움.
- **블록 짧게 탭**: 상세 모달.
- **블록 0.4초 꾹 누름**: 보라 링 + 양쪽 핸들 등장 → 에디트 모드 진입.
- **에디트 블록 드래그**: 가로=날짜, 세로=시간 (15분 스냅).
- **에디트 블록 위/아래 핸들**: 시간 길이 조절.
- **에디트 해제**: 블록 우상단 X / 빈 칸 탭 / 다른 블록 탭 / 모달 열기 모두 자동 해제.
- **lane 자동 분할**: 같은 시간 겹치는 블록은 가로로 나눔.

```
┌─────────────────────────────────────────────┐
│      YYYY년 M월              ◂ [오늘] ▸    │
│  일   월   화   수   목   금   토            │
├─────────────────────────────────────────────┤
│  …                                          │
└─────────────────────────────────────────────┘
```

#### 핵심 동작

- **셀당 최대 3개** 일정/할일 + `+N` 표시 (4건 이상).
- **셀 탭**: `/timeline?d=YYYY-MM-DD` 로 이동.
- **좌우 화살표**: 월 이동.

### 6.5 상세 모달 (모든 뷰에서 공통)

```
┌───────────────────────────────────┐
│ ━━━ (드래그 핸들 바)              │
│ [ ✕ ]            YYYY.M.D HH:MM 생성│
│                                   │
│ 제목 (편집 가능)                  │
│                                   │
│ 유형: ( 일정 │ 할일 )             │
│ 상태: ( 예정 │ 진행중 │ … )       │
│ 시간: [ 날짜 ▾ ][ 시간 ▾ ]       │
│ 프로젝트: [ 선택된 칩 ✕ ]         │
│         [ 검색 또는 새로 만들기 ] │
│ 설명: [ 큰 텍스트 영역 ]          │
├───────────────────────────────────┤
│ ✓완료  ✕취소  📅다음날  🗑️삭제    │
└───────────────────────────────────┘
```

#### 핵심 동작

- **상단 핸들 영역 아래로 드래그**: offset > 120px 또는 velocity > 500 시 자동 닫힘.
- **삭제**: 1차 클릭 → "진짜 삭제?" → 2차 클릭으로 확정.
- **프로젝트 검색창**에 없는 이름 입력 → "[입력값] 새 프로젝트 만들기" → 노션 multi_select 옵션 자동 생성.
- **모든 필드 편집은 즉시 화면 반영 + 백그라운드 노션 PATCH** (optimistic UI).

### 6.6 새 태스크 모달

```
┌───────────────────────────────────┐
│ ━━━                               │
│ [ ✕ ]    새 태스크    [ + 추가 ]  │
│                                   │
│ 뭘 해야 하지?            [ 🎤 ]   │ ← 음성 입력
│                                   │
│ ( 일정 │ 할일 )                   │
│ 시간: [ 날짜 ][ 시간 ]            │
│ [프로젝트 검색/생성]              │
└───────────────────────────────────┘
```

#### 핵심 동작

- **자동 포커스** + **Enter로 즉시 추가**.
- **음성 버튼**: 한국어 음성 인식 → 제목 뒤에 append.
- **빈 시간대 탭**으로 들어왔을 때 시작/종료 자동 채움.

### 6.7 잠금 해제 (`/login`)

```
┌───────────────────────────────────┐
│            🔒                     │
│         잠금 해제                 │
│       6자리 코드 입력             │
│                                   │
│   ●  ●  ●  ·  ·  ·                │
└───────────────────────────────────┘
```

#### 핵심 동작

- **6자리 영문 + 숫자**.
- **마스킹**: 입력된 자리는 `●`, 빈 자리는 `·`. 실제 값은 화면에 노출 안 됨.
- 6번째 입력 즉시 자동 제출.
- 모바일에서 숫자 키패드 자동 호출.
- 실패 시 입력 초기화 + 빨간 메시지 ("코드가 틀려요").
- 성공 시 30일 쿠키.

## 7. 동기 흐름

```
사용자 액션 (탭/스와이프/드래그)
    ↓ 즉시 (optimistic UI)
앱 화면 변경
    ↓ 백그라운드 (수백 ms)
서버 API → 노션 PATCH
    ↓ 즉시
노션 DB 변경
```

> 노션을 외부 시스템(구글 캘린더 등)과 동기하려는 경우, 그건 사용자 워크스페이스의 별도 자동화 책임이고 앱 외부. 앱은 노션까지만 보장한다.

### Hydration

1. 첫 렌더 시 빈 배열 + 스켈레톤
2. `GET /api/tasks` 호출 → 노션 데이터 받음
3. 결과를 store에 hydrate → 실데이터 표시
4. 페이지 focus 시 자동 재호출

## 8. 비기능 요구사항

### 성능
- LCP < 2.5s on 3G mid.
- 인터랙션 < 100ms (optimistic UI).
- 노션 fetch는 매번 fresh, 클라이언트 메모리 캐시.

### 가용성
- 노션 API 실패 시 silent. 다음 focus 시 재시도.
- 토큰 미설정 시 빈 상태 메시지.

### 보안
- 6자리 패스코드 (서버 환경변수).
- 세션 쿠키: httpOnly + sameSite=lax + 30일.
- 노션 토큰은 서버에서만, 클라이언트 번들에 절대 노출 안 됨.
- 패스코드 미설정 시 인증 OFF (개발 편의용).

### 접근성
- 모든 인터랙티브 요소 `aria-label`.
- 색상 대비 WCAG AA.
- 시스템 폰트 사이즈 존중 (`minimumScaleFactor` 0.8).

### 모바일 PWA
- `manifest.webmanifest`: standalone, theme-color, 인디고 아이콘.
- iOS 풀스크린(`apple-mobile-web-app-capable`).
- 안전영역(`env(safe-area-inset-*)`).
- `touch-action: pan-y` 로 페이지 세로 스크롤 보장.

### 둥글기 / 그림자

- 카드: `rounded-2xl` (16px), 그림자 없음 (열린 느낌)

- 칩/버튼: `rounded-full`
- 입력: `rounded-xl` (12px)
- FAB: 인디고 그림자 (`shadow-xl shadow-indigo-500/30`)
- 드롭다운: `shadow-xl`
- 에디트 블록: `shadow-lg ring-2 ring-primary`

### 간격

- 카드 간 간격: `space-y-1`

- 카드 padding: `px-4 py-3.5`
- 모달 padding: `px-5 py-4`
- 하단 탭 높이: ≈ 50px + safe-area
- FAB 위치: `bottom: env(safe-area-inset-bottom) + 88px`, `right: 20px`
- 터치 타겟 최소: 44pt × 44pt

## 14. 디자인 원칙

1. **이모지를 헤더에 쓰지 않는다** — 색·점·아이콘으로 대체.
2. **카드 프레임은 인터랙티브 영역에만** — 일반 항목은 열린 느낌.
3. **모든 클릭 가능 요소는 `cursor-pointer`** + 최소 44pt 터치 타겟.
4. **다크 모드 자동** — `prefers-color-scheme` 따라 토큰 변경.
5. **모달은 시트 형태** — 상단 핸들 바 + 아래로 드래그하여 닫기.
6. **빈 상태는 친절한 메시지**.
7. **로딩**은 스켈레톤 + syncing 인디케이터. 진행 막대 안 씀.
8. **에러는 토스트 또는 인라인** — 모달은 닫지 않고 메시지만.

## 15. 자주 하는 오해

| 오해 | 정답 |
|------|------|
| "스와이프 후 노션 반영이 안 보인다" | 즉시 반영됨. UI는 optimistic이라 즉시 변경 |
| "노션 토큰을 클라이언트에서 직접 호출" | 절대 안 됨. 클라이언트는 `/api/tasks`만 호출, 토큰은 서버에서만 |
| "프로젝트 칩이 모든 후보를 보여야 한다" | ❌ 현재 데이터에 실제 있는 프로젝트만 자동 추출 |
| "완료된 옛날 task가 안 보인다" | 완료 탭은 기본 `이번주`. `전체` 선택해야 다 보임 |
| "타임라인 블록 탭하면 바로 드래그됨" | ❌ 짧게 탭은 상세 모달. 0.4초 꾹 눌러야 에디트 모드 |
| "에디트 모드는 자동 해제 안 된다" | ❌ 빈 칸 탭, 다른 블록 탭, 모달 열기 모두 해제 |
| "스와이프가 페이지 좌우 스크롤과 충돌" | ❌ direction lock + touch-action으로 분리됨 |
| "PIN 입력값이 화면에 보인다" | ❌ 마스킹 (`●`). 실제 input은 transparent |
